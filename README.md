## Things I've built

- [Sahay](https://github.com/PrachiBhowal/SAHAY) — Dementia care platform built with a team of 6. I built the adaptive difficulty engine, caregiver distress alerts, and a pattern-recognition memory game end-to-end. React, Node.js, IndexedDB, REST.
- [Fashion Assistant](https://github.com/Mokshitavp1/fashion_assistant) — Wardrobe and outfit recommendation app using YOLOv8 for clothing and pose analysis, a feedback loop, and separate data per account. FastAPI, React, Redis, Celery, Docker. 14 stars, 4 forks.
- [Acoustic Sonar](https://github.com/Mokshitavp1/acoustic_sonar) — Laptop-only sonar using near-ultrasonic chirps, echo capture, and cross-correlation to estimate distance and motion, with live waveform and radar visuals. In progress.
- [Flash Flood Warning System](https://github.com/Mokshitavp1/flash_flood_warning_system) — Early-warning pipeline that combines weather observations, satellite sequences, terrain data, and downhill flow routing to identify downstream flood risk.
- [Docket](https://github.com/Mokshitavp1/docket) — Meeting intelligence tool that transcribes meetings, extracts tasks, assigns owners, and sets deadlines.
